# ADHD Winner — test d'une semaine avec 5 personnes ayant un TDAH

> **État : dispositif prêt, résultats à obtenir.** Aucun participant n'a encore été recruté.
> Ce document ne contient aucun résultat inventé : les tableaux de la section 6 sont vides et seront remplis pendant le test.

## 1. Objectif

Vérifier, avec de vraies personnes ayant un TDAH diagnostiqué, que ADHD Winner les aide à **passer de l'intention à l'action** :
écrire une tâche → choisir Personal ou Work → la programmer si besoin → la retrouver (liste, tableau, calendrier) → utiliser Help me start pour commencer → suivre ses progrès.

## 2. Participants

- 5 adultes avec un **TDAH diagnostiqué** (déclaré par la personne ; on ne demande pas de document médical).
- Au moins 2 utilisateurs d'iPhone et 2 d'Android, si possible 1 ou 2 personnes qui préfèrent l'arabe.
- **Consentement écrit avant de commencer** (modèle en section 8). La personne peut arrêter à tout moment, sans justification.
- Aucune donnée de santé n'est collectée par l'application. Le diagnostic n'est noté que dans le tableau de recrutement, gardé hors de l'application et supprimé à la fin du projet.

## 3. Déroulé (7 jours)

| Jour | Ce qui se passe | Durée |
|---|---|---|
| J0 | Appel d'accueil : installation sur l'écran d'accueil, autorisation des notifications, **observation de la première tâche créée sans aide** (section 4) | 20 min |
| J1–J6 | Utilisation libre. Un message court chaque soir : « Une chose qui a aidé ? Une chose qui a gêné ? » (réponse facultative) | 1 min / jour |
| J3 | Mini-appel : rappels reçus ou non, problèmes techniques | 10 min |
| J7 | Entretien final (section 5) + envoi du fichier de chiffres : Profil → **My starts** → « Share my numbers (no task names) » | 25 min |

## 4. Observation du premier jour (sans aider la personne)

Demander : « Ajoute une chose que tu dois faire demain à 14 h. » Noter sans intervenir :

| Question | Oui / Non | Temps | Remarque |
|---|---|---|---|
| Trouve où écrire la tâche ? | | | |
| Comprend le choix Personal / Work ? | | | |
| Arrive à mettre une date et une heure ? | | | |
| Retrouve la tâche dans le calendrier, au bon jour et à la bonne heure ? | | | |
| Trouve le bouton tableau et revient à la liste ? | | | |
| Utilise Help me start et appuie sur Start ? | | | |

Puis : fermer complètement l'application, la rouvrir, vérifier que la tâche est toujours là.

## 5. Entretien final (questions ouvertes)

1. Qu'est-ce qui t'a aidé à **commencer** une tâche cette semaine ?
2. Help me start : la première étape proposée était-elle assez petite ? Trop vague ? Un exemple ?
3. Les rappels ont-ils sonné quand tu en avais besoin ? Sur quel téléphone, application ouverte ou fermée ?
4. La différence Personal / Work était-elle claire ? Utile ?
5. Le tableau t'a-t-il servi ? Quand ?
6. Les XP et les récompenses : motivants, neutres ou dérangeants ?
7. (Arabophones) La version arabe de Help me start était-elle naturelle ? Une phrase étrange ?
8. Qu'est-ce qui t'a fait abandonner l'application, si c'est arrivé ?

## 6. Mesures

### Mesures enregistrées par l'application (sur le téléphone, sans nom de tâche)

| Mesure | Définition exacte |
|---|---|
| **Session Help me start** | Une ouverture de la fenêtre Help me start (un identifiant par session). |
| **Session éligible** | Une session où l'application a affiché **au moins une étape concrète** (de Noor ou du moteur hors ligne). |
| **Tâche commencée** | Dans une session éligible, la personne a appuyé sur **Start** (minuteur), ou choisi **« I started »**, ou indiqué **avoir terminé une étape**. Ouvrir la fenêtre, lire l'étape ou appuyer sur « Start this step » ne suffit pas. Comptée **une seule fois par session**, même après un double appui ou un rechargement. |
| **Start Rate** | Sessions éligibles avec démarrage ÷ sessions éligibles × 100 (Profil → My starts). |
| **Tâches différentes commencées** | Nombre de tâches distinctes associées à une session avec démarrage (évite de confondre sessions et tâches). |
| Résultat de la session | `started`, `completed_step`, `stopped` ou `abandoned`. |
| Délai avant de commencer | Secondes entre l'ouverture et le premier démarrage (dans le fichier exporté). |

Le fichier exporté contient : date de chaque session, étape affichée oui/non, démarrage oui/non, délai, résultat, compteurs d'événements. **Il ne contient ni nom de tâche, ni texte écrit par la personne, ni prénom.**

## 7. Rapport final (modèle)

1. Problèmes rencontrés (par fréquence : combien de participants sur 5)
2. Fonctionnalités réellement utilisées
3. Erreurs techniques (téléphone, version, étapes pour reproduire)
4. Start Rate : par participant et global (somme des démarrages ÷ somme des sessions éligibles)
5. Difficultés dans le parcours tâche → catégorie → horaire → calendrier → Help me start
6. Améliorations prioritaires (impact × nombre de participants touchés)

Règle : chaque affirmation du rapport doit renvoyer à une observation, une citation ou un chiffre exporté.
